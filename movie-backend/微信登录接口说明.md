# 微信登录接口说明

## 接口地址

```
POST /auth/wechat/login
```

## 请求参数

```json
{
  "code": "微信小程序wx.login()获取的code"
}
```

## 响应数据

```json
{
  "token": "生成的UUID token",
  "openId": "微信openId",
  "userId": 用户ID
}
```

## 使用流程

1. **前端调用微信登录**
   ```javascript
   wx.login({
     success: function(res) {
       if (res.code) {
         // 发送 res.code 到后台换取 openId
         wx.request({
           url: 'http://localhost:8080/auth/wechat/login',
           method: 'POST',
           data: {
             code: res.code
           },
           success: function(result) {
             // 保存 token 和用户信息
             wx.setStorageSync('token', result.data.token);
             wx.setStorageSync('openId', result.data.openId);
             wx.setStorageSync('userId', result.data.userId);
           }
         });
       }
     }
   });
   ```

2. **后续请求携带token**
   ```javascript
   wx.request({
     url: 'http://localhost:8080/api/xxx',
     header: {
       'Authorization': 'Bearer ' + wx.getStorageSync('token')
     }
   });
   ```

## 配置说明

### 测试模式（无需配置）

如果使用测试号或暂时没有AppID，可以直接运行，系统会自动使用测试模式：
- 不会调用微信接口
- 根据code生成模拟的openid
- 功能完全可用，适合开发测试

### 正式模式（需要配置）

在 `application.yml` 中配置你的小程序信息：

```yaml
wechat:
  appid: your_appid      # 替换为你的小程序AppID
  secret: your_secret    # 替换为你的小程序AppSecret
```

配置后会自动切换到正式模式，调用真实的微信接口。

## 注意事项

1. **code只能使用一次**：微信的code只能使用一次，5分钟内有效
2. **token存储**：当前使用内存存储，服务重启后token会失效
3. **生产环境**：建议将token存储到数据库或Redis中
