# 启动后端服务说明

## 问题说明

如果小程序出现 `ERR_CONNECTION_REFUSED` 错误，说明后端服务没有启动。

## 启动步骤

### 1. 进入后端项目目录

```bash
cd movie-backend
```

### 2. 先设置数据库环境变量（必需）

后端现在会读取系统环境变量 `MYSQL_PASSWORD`，请设置为你自己的 MySQL 密码：

```powershell
# Windows PowerShell（仅当前终端有效）
$env:MYSQL_PASSWORD = "你的MySQL密码"
```

如有需要，也可以同时设置其他变量：

```powershell
$env:MYSQL_HOST = "127.0.0.1"
$env:MYSQL_PORT = "3306"
$env:MYSQL_DB = "movie_db"
$env:MYSQL_USER = "root"
```

### 3. 使用Maven启动（可选）

```bash
mvn spring-boot:run
```

说明：当前项目未包含 `mvnw` 启动脚本，如果你本机没有安装 Maven，请直接使用下面的 IDE 启动方式。

### 4. 或者使用IDE启动

- **IntelliJ IDEA**: 打开 `MovieBackendApplication.java`，右键选择 `Run 'MovieBackendApplication'`
- **Eclipse**: 打开 `MovieBackendApplication.java`，右键选择 `Run As` -> `Java Application`
- **VS Code**: 安装Spring Boot扩展，然后运行

### 5. 验证服务是否启动成功

启动成功后，访问以下URL应该能看到响应：

- `http://localhost:8080/api/test` - 测试接口
- `http://localhost:8080/api/` - 服务信息

## 注意事项

1. **端口占用**: 确保8080端口没有被其他程序占用
2. **防火墙**: 如果需要在真机上测试，确保防火墙允许8080端口
3. **网络配置**: 真机测试时，需要将 `config.js` 中的 `backendApiUrl` 改为你的电脑IP地址，例如：
   ```javascript
   var backendApiUrl = 'http://192.168.1.100:8080/api'
   ```

## 离线模式

如果不想启动后端服务，小程序会自动降级为**本地存储模式**：
- 所有数据仅保存在本地
- 不会显示错误提示
- 功能正常使用，但数据不会跨设备同步

## 生产环境部署

生产环境需要：
1. 将后端服务部署到服务器
2. 修改 `config.js` 中的 `backendApiUrl` 为生产环境地址
3. 配置HTTPS（微信小程序要求）
