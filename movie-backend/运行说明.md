# 运行Spring Boot项目

你的系统没有安装Maven，有两种方式运行项目：

## 方式1：使用IDE运行（推荐，最简单）

### 使用 IntelliJ IDEA

1. 打开 IntelliJ IDEA
2. 选择 `File` -> `Open`，选择 `movie-backend` 文件夹
3. 等待IDEA自动下载Maven依赖（首次可能需要几分钟）
4. 找到 `src/main/java/com/movie/MovieBackendApplication.java` 文件
5. 右键点击文件，选择 `Run 'MovieBackendApplication.main()'`
6. 项目启动后，访问：`http://localhost:8080/test`

### 使用 Eclipse

1. 打开 Eclipse
2. 选择 `File` -> `Import` -> `Existing Maven Projects`
3. 选择 `movie-backend` 文件夹
4. 等待Eclipse下载Maven依赖
5. 找到 `MovieBackendApplication.java`，右键 -> `Run As` -> `Java Application`
6. 项目启动后，访问：`http://localhost:8080/test`

## 方式2：安装Maven后使用命令行

### 安装Maven

1. 下载Maven：https://maven.apache.org/download.cgi
   - 下载 `apache-maven-3.8.6-bin.zip`
2. 解压到某个目录，例如：`C:\Program Files\Apache\maven`
3. 配置环境变量：
   - 新建系统变量 `MAVEN_HOME` = `C:\Program Files\Apache\maven`
   - 在 `Path` 变量中添加：`%MAVEN_HOME%\bin`
4. 验证安装：
   ```powershell
   mvn -version
   ```

### 使用Maven运行

```powershell
cd movie-backend
mvn spring-boot:run
```

## 验证项目运行

项目启动成功后，在浏览器访问：
```
http://localhost:8080/test
```

如果看到 "Spring Boot 项目启动成功！"，说明项目运行正常。
